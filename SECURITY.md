# Security Policy

## Supported Versions

We actively support and provide security patches for the main development branch.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Dhaka Bus Vara:

1. **Do not create a public GitHub issue.**
2. Please report the issue privately by contacting the repository maintainers or using GitHub Private Vulnerability Reporting.
3. Include details of the vulnerability, reproduction steps, and any potential exploit scenarios.

We will acknowledge receipt within 48 hours and work with you to patch the issue before public disclosure.
